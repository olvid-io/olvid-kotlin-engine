# Olvid Kotlin Engine

Olvid is a private and secure end-to-end encrypted messenger.

This repository contains the Olvid Kotlin Engine, as used in the Android and Windows/Linux versions.

This engine implements the cryptography and security layers of the application, identity and contact/group management, as well as the network API to communicate with the server infrastructure. For more details about the application architecture, please refer to the [Android application repository](https://github.com/olvid-io/olvid-android).

## Using it

This engine is a library and cannot run on its own.

This repository is used for the publication of this library to Maven: https://mvnrepository.com/artifact/io.olvid.messenger/olvid-kotlin-engine
